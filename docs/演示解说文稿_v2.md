## L2 · 痛点与核心思想（0:40–1:10，约 30 秒）

**画面**：镜头标题「L2 · 痛点：多智能体协作的三大瓶颈」→ 三张痛点卡片依次出现（① Token 黑洞 / ② 状态失真 / ③ 经验蒸发）→「SYNAPSE 的核心思想」三条 → 正反馈闭环动画 Memory↗ → Predict↑ → Residual↓ → Comm↓。

**解说词**：

> 要理解 SYNAPSE 解决了什么，先看当前多智能体协作的**三大瓶颈**。
>
> *(等 ① 出现)* **第一，Token 黑洞**：Agent 之间用自然语言反复传话，通信账单爆炸，复杂度接近 O(N²)。
>
> *(等 ② 出现)* **第二，状态失真**：中间推理结果要在内部表示和文本之间反复编解码，带来语义损耗和时延。
>
> *(等 ③ 出现)* **第三，经验蒸发**：任务做完就忘，对话越长，token 堆积越快——我们实测放大了 1.31 倍。
>
> *(等核心思想出现)* SYNAPSE 的回答是——**发送惊讶残差，而非全量信息**。发送方预测接收方已经知道什么，只传对方预测不到的那部分增量；非文本状态用 CAS 句柄零拷贝传递；经验沉淀进共享记忆，越用预测越准、残差越稀疏。
>
> *(等闭环动画)* 这形成了一个**正反馈闭环**：记忆增长、预测增强、残差减少、通信降低，循环往复——这就是"协作即压缩"的引擎。

## L5 · 收缩律、因果归因与消融阶梯（2:25–3:05，约 40 秒）

**画面**：镜头标题「L5 · 协作速率收缩律 + 97.6% 因果归因」→ 双序列折线图（B1 下降 vs 负例上升）→ 三条对比说明 → 97.6% 因果归因滚动 + 公式 → 组件消融阶梯条形（4108>3601>1914>1461）。

**解说词**：

> 这一镜是团队的核心理论贡献——**协作速率收缩律**，以及它的因果证明。
>
> *(等折线图)* 这张图是真实 signal 实验的残差字节轨迹。橙色是完整链路 B1：从第一轮 2787 字节，一路降到第五轮 960，**收缩 65.6%**，命中率 0.8。红色是负例，也就是任务之间没有共享主题——它不降反升。
>
> *(等三条对比)* 关键的对照在这：当我们**关闭记忆**（B3），收缩骤降到只有 1.6%——几乎不收缩。
>
> *(等 97.6% 滚动)* 那么收缩到底有多少来自记忆复用？我们算一下：(B1 的 65.6% 减去 B3 的 1.6%) 除以 B1——等于 **97.6%**。也就是说，97.6% 的通信压缩，因果地源于记忆复用机制，而不是任务本身相似带来的巧合。
>
> *(等消融阶梯)* 最后这组**组件消融阶梯**进一步证明每个零件都不可或缺：纯潜空间传递最高 4108 字节，关掉心智预测器 3601，关掉跨任务巩固 1914，完整链路最低 1461——**阶梯式上升，缺一不可**。

## L6 · 漂移感知与越长越省（3:05–3:40，约 35 秒）

**画面**：镜头标题「L6 · 漂移感知(AUC=1.0) + 越长越省」→ 漂移感知表（熟悉 1240.6 / 漂移 3843.0 / 检索 AUC 0.227）→ 漂移柱形对比 → CoQA 越长越省表 → 命中率 0.921 滚动 → M7 跨组复用 → 三档协议迁移。

**解说词**：

> 这一镜讲两个发现，都来自说明书第四、五章。
>
> *(等漂移表)* 第一个是**漂移感知**。当任务分布从"熟悉"切换到"漂移"，平均残差字节从 1240.6 骤升到 3843.0，**回弹 246.5%**。更关键的是，残差信号对这个切换的检测 AUC 达到 **1.0**——完美区分；而传统的检索相似度信号只有 0.227。这意味着，**通信成本本身可以反向用作免费的系统健康传感器**。
>
> *(等 CoQA 表)* 第二个是 CoQA 对话场景的**越长越省**。三段对话，轮数越长，末轮省的 token 越多：最长的一段 15 轮，末轮省了 **1357 个 token**。
>
> *(等命中率)* 整体记忆命中率 **0.921**，35 轮里命中历史记忆，而且那段最长对话的答案质量还提升了——ΔF1 达到 **+0.089**。
>
> *(等 M7)* M7 实验进一步证明经验能**跨任务迁移**：G2 复用 G1 的记忆，线缆字节再省 40.67%——协作经验随任务数持续增值。
>
> *(等三档协议)* 最后，三档混合协议会自动迁移：residual 档 1 次、embedding 档 4 次、text 回退 0 次——**零降级**，通信策略随经验动态演化。
