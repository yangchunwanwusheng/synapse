# SYNAPSE 部署文档（赛题 M10）

目标平台：**openEuler 24.03-LTS-SP3**（交付红线：可编译、运行、测试）。
基座 smolagents 为**纯 Python 轻依赖**（无 torch/transformers/langchain），无平台特定依赖；**无 GPU 需求**。
机密（`PARATERA_API_KEY`）**仅放 `.env`，绝不入镜像/代码/Git**。

---

## 0. 两条部署路径
| 路径 | 适用 | 命令入口 |
|---|---|---|
| A. 原生 uv | 开发机 / openEuler 裸机 | `uv sync` + `uv run synapse ...` |
| B. 容器（推荐复现） | openEuler + Docker；评审一键复现 | `docker compose run --rm synapse ...` |

两条路径默认入口都是**离线自检**（mock LLM + hash 嵌入，零网络/零密钥），评审无需密钥即可见五项 PASS。

---

## A. 原生 uv 部署（openEuler 24.03）
```bash
# 1) 系统依赖（openEuler 24.03 自带 Python 3.11）
sudo dnf install -y python3 python3-pip
python3 -m pip install --user uv          # 统一包管理（项目约定）

# 2) 同步依赖（核心 smolagents；真实路径加 --extra api）
uv sync                                   # 离线 mock 足够
uv sync --extra api                       # 真实 Paratera LLM（openai 客户端）

# 3) 离线自检（零网络/零密钥）→ 期望 SMOKE PASSED
uv run synapse smoke

# 4) 真实实验（需密钥）
cp .env.example .env                      # 填 PARATERA_API_KEY
uv run synapse probe                      # 输出形态探针
uv run synapse signal --rounds 10         # 关联+负例 A/B，存 runs/signal_*/
```

---

## B. 容器部署（Docker / docker-compose）
```bash
# 构建（openEuler 24.03-LTS 基础镜像）
docker build -t synapse:latest .
# 或： docker compose build

# 离线自检（无需密钥）→ 期望 SMOKE PASSED
docker run --rm synapse:latest
# 或： docker compose run --rm synapse

# 真实实验（密钥经 --env-file 注入，不入镜像）
cp .env.example .env                       # 填 PARATERA_API_KEY
docker run --rm --env-file .env synapse:latest signal --rounds 10
# 或： docker compose run --rm synapse signal --rounds 10
```

- **健康检查**：镜像内置 `HEALTHCHECK = synapse smoke`（离线、不依赖外部服务）。
- **端口**：无（CLI 批处理型原型，非常驻服务）。
- **环境变量**：`PARATERA_API_KEY`（真实路径必需，经 `.env`/`--env-file` 注入）；可选 `PYTHONIOENCODING=utf-8`。
- **日志**：stdout（JSON 指标 + PASS/FAIL）；实验产物落 `runs/signal_*/result.json`（挂卷持久化：`-v "$PWD/runs:/app/runs"`）。
- **密钥安全**：`.env` 在 `.dockerignore` 中，**不进镜像**；仅运行期注入。

## D. openEuler 系统技术增强（M10 鼓励项，路线）
- **字节实测**：当前用应用层字节计数；openEuler 上可加 **eBPF**（socket 层实测 Agent 间字节），缺 eBPF 权限时降级 socket 计数兜底。
- **沙箱（M11）**：smolagents 本地执行器跑 CodeAct；生产可切其 Docker/E2B 沙箱做强隔离。
- **共享内存/IPC**：当前共享记忆为进程内 CAS+Store；多进程部署可换 Socket/共享内存后端（接口已隔离在 `memory/`、`stateplane/cas.py`）。

## E. 在 openEuler 24.03-LTS 容器内的复现验证（2026-06-20，已实测）
- 基础镜像：`openeuler/openeuler:24.03-lts`（Docker 29.1.2 实测 build 通过）。
- `docker build -t synapse:latest .` → 成功；镜像 **597MB**（纯 Python 轻依赖）。
- `docker run --rm synapse:latest` → **SMOKE PASSED**（5 项检查全 PASS，零网络/零密钥）。
- 运行身份 = **非 root**（`whoami=synapse`, uid 1001，最小权限）。
- `docker compose run --rm synapse` → **SMOKE PASSED**（`.env` 缺省不报错，`required:false`）。
- 内置 `HEALTHCHECK = synapse smoke`，compose 配置 `docker compose config` 校验通过。
- 真实实验（容器内）：`docker run --rm --env-file .env synapse:latest signal --rounds 10`（密钥仅运行期注入，不入镜像，已 `.dockerignore` 排除）。

> 注：交付目标 openEuler 24.03-LTS-SP3；`24.03-lts` 为该 LTS 线滚动标签，依赖纯 Python 与 SP 版本无关，SP3 上行为一致。生产强隔离可切 smolagents 的 Docker/E2B 沙箱执行 CodeAct（M11）。
