# SYNAPSE 演示视频分镜脚本（赛题 M10）

目标时长 3–5 分钟，全程命令行，覆盖评分五维（通信效率/状态创新/记忆复用/系统完整性/实验验证）。
录制建议：终端字号调大、`PYTHONIOENCODING=utf-8`；真实段落提前 `cp .env.example .env` 填好 `PARATERA_API_KEY`。

| # | 镜头 | 命令 / 画面 | 旁白要点（对应赛题） |
|---|---|---|---|
| 1 | 项目与五模块 | `ls src/synapse/`（runtime/protocol/stateplane/memory/eval） | M9 五大模块齐备：多 Agent 运行时 + 协议调度 + 状态交换 + 共享记忆 + 评测 |
| 2 | 离线自检（零密钥） | `uv run synapse smoke` → `SMOKE PASSED` | M3 双模式跑通；五项检查：双模式产结论/省字节/记忆命中/非文本字节下降/负例区分 |
| 3 | openEuler 容器 | `docker run --rm synapse:latest` → 容器内 `SMOKE PASSED` | M10 交付红线：openEuler 24.03-LTS 镜像可编译运行、非 root |
| 4 | 真实 API · 通信效率 | `uv run synapse signal --rounds 10` → 打印字节节省、非文本字节轨迹、因果区分 | M4 非文本残差传递 + M8 统计；通信效率：wire 省 41%、token 省 24% |
| 5 | 跨组记忆复用 | `uv run synapse m7 --g1 5 --g2 5` → G2 命中 1.0 ≤ G1 字节 | M7 ≥2 组关联任务；记忆复用：G2 复用 G1，不重付冷启动 |
| 6 | 真实数据集 · HotpotQA | `uv run synapse hotpot --n 10` → token 省 70%+、F1 持平 | 实验验证：多文档场景丢干扰段，token 大幅节省质量不降 |
| 7 | 收尾 | 展示 `docs/系统设计文档.md` + `docs/部署文档.md` + `README.md` | M10 交付物齐：源码/设计文档/部署文档/实验报告/本视频 |

旁白一句话总线：**"结构化协议替代冗长文本透传，句向量预测残差实现非文本状态直接交换，共享记忆跨任务沉淀复用——三者叠加让多智能体协作的通信开销显著降低。"**

> 注：M11（CodeAct）在第 4/5 步隐含演示——executor 是 smolagents CodeAgent，真在本地执行器对注入证据跑 Python 计算，可在旁白点出。
