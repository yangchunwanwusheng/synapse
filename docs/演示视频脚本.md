# SYNAPSE 演示视频分镜脚本（赛题 M10，2026-07-08 更新）

目标时长 3–5 分钟，全程命令行，覆盖评分五维（通信效率/状态创新/记忆复用/系统完整性/实验验证）。
录制建议：终端字号调大、`PYTHONIOENCODING=utf-8`；真实段落提前 `cp .env.example .env` 填好 `PARATERA_API_KEY`。

| # | 镜头 | 命令 / 画面 | 旁白要点（对应赛题） |
|---|---|---|---|
| 1 | 项目与五模块 | `ls src/synapse/`（runtime/protocol/stateplane/memory/eval） | M9 五大模块齐备：多 Agent 运行时 + 协议调度 + 状态交换 + 共享记忆 + 评测 |
| 2 | 离线自检（零密钥） | `uv run synapse smoke` → `SMOKE PASSED` | M3 双模式跑通；五项检查：双模式产结论/省字节/记忆命中/非文本字节下降/负例区分 |
| 3 | openEuler 容器 | `docker run --rm synapse:latest` → 容器内 `SMOKE PASSED` | M10 交付红线：openEuler 24.03-LTS 镜像可编译运行、非 root |
| 4 | 真实 API · 通信效率（HotpotQA） | `uv run synapse hotpot --n 20` → token 省 75.5%、F1 synapse 0.757 > text 0.714 | M4 非文本残差传递 + M8 统计；通信效率：省 75% token，质量不降反升 |
| 5 | 多跳检索适配（MuSiQue） | `uv run synapse musique --n 10 --retrieval twohop` → 省 84.3%、ΔF1 +0.070 | 检索模式匹配任务结构：MuSiQue 链式多跳用 twohop 补桥接段 |
| 6 | 机制验证 + 归因 ablation | `uv run synapse signal --rounds 5` → drop 40%；再跑 `--no-memory` → drop 6.4% | M4 非文本残差随记忆增长下降 40%；无记忆 ablation 降至 6.4% 证因果源于记忆 |
| 7 | 跨组记忆复用 | `uv run synapse m7 --g1 5 --g2 5` → G2 命中 ≥ G1 | M7 ≥2 组关联任务；记忆复用：G2 复用 G1，不重付冷启动 |
| 8 | 对话式记忆复用 | `uv run synapse coqa --convs 3` → 命中 0.92、ΔF1 +0.020 | 记忆复用：CoQA 跨轮命中 0.92，对话越长省得越多 |
| 9 | 收尾 | 展示 `docs/系统设计文档.md` + `docs/部署文档.md` + `docs/实验报告-2026-07-08-update.md` | M10 交付物齐：源码/设计文档/部署文档/实验报告/本视频 |
