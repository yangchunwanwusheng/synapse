## 已知局限（诚实标注）

1. **seed=exploratory**：所有 235B 实验为单 seed（temp=0 greedy），标注 exploratory。HotpotQA 已扩至 N=10，MuSiQue/CoQA 为 N=3。3 seed 补强（confirmed）待后续。
2. **HotpotQA ΔF1=−0.100**：N=10 下 F1 略降（集中在 2 道 hard 题答案表达差异），金标召回稳定 0.9，通信压缩不牺牲召回。需更大样本或检索模式调优确认方向。
3. **演示视频待录制**：脚本就绪（9 镜头，3-5 分钟），需本机录屏。
4. **signal 路径 llm_input_tokens 未采集**：hotpot/musique/coqa 路径正常，signal 的 Metrics 聚合与 LLM 计数器交互待修（不影响机制结论）。
5. **无系统加分项**：赛题鼓励的 eBPF/WASM/共享内存未实现（纯 Python 暴力 cosine，非必须；CAS + 残差编码已是系统层机制创新）。
