## 已知局限（诚实标注）

1. **seed=exploratory**：所有 235B 实验为单 seed（temp=0 greedy），标注 exploratory。3 seed 补强（confirmed）待后续。
2. **MuSiQue twohop N=30 未完成**：N=10 结果支撑结论，大规模因 API 超时未完成。
3. **演示视频待录制**：脚本就绪（9 镜头，3-5 分钟），需本机录屏。
4. **无系统加分项**：赛题鼓励的 eBPF/WASM/共享内存/向量数据库未实现（纯 Python 暴力 cosine，非必须）。
