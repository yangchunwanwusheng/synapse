## 一、通信效率 + 答案质量（赛题 通信效率 25 分 + 状态传递 20 分）

### 1.1 主结果：三数据集 per-dataset 最优配置

| 数据集 | 任务类型 | N | 检索模式 | token 节省 | text F1 | synapse F1 | ΔF1 | 金标召回 |
|---|---|---|---|---|---|---|---|---|
| **HotpotQA** | bridge 型多跳 | 20 | single k=3 | **75.5%** | 0.714 | 0.757 | **+0.043** | 0.85 |
| **MuSiQue** | 链式多跳 | 10 | twohop k=3 | **84.3%** | 0.170 | 0.240 | **+0.070** | 0.70 |
| **CoQA** | 对话式 QA | 3 conv | — | **9.7%** | 0.662 | 0.682 | **+0.020** | hit 0.92 |

**核心结论**：三数据集均 ΔF1 ≥ 0（synapse 答案质量不降反升），同时省 75-84% token（多文档场景）或 9.7%（对话场景）。

### 1.2 检索模式需匹配任务结构（新发现）

| 数据集 | single ΔF1 | twohop ΔF1 | 最优模式 | 原因 |
|---|---|---|---|---|
| HotpotQA (bridge 型) | **+0.043** | −0.127 | **single** | twohop 嵌入查询扩展引入噪声段（召回 0.85→0.78） |
| MuSiQue (链式) | −0.066 | **+0.070** | **twohop** | single 检索不到桥接段；twohop 查询扩展补上 |

> 科学发现：黑盒检索-应答分离架构的检索模式需匹配多跳任务结构。HotpotQA 的 bridge 型（两段标题互现）适合 single；MuSiQue 的链式（第二跳依赖第一跳内容）适合 twohop。

### 1.3 CoQA per-turn token 曲线（记忆复用→后轮更省）

| 对话 | 轮数 | text per-turn 增长 | synapse per-turn 增长 | 后半 gap |
|---|---|---|---|---|
| coqa-0 | 12 | +28% | +12% | 70 tokens |
| coqa-1 | 11 | +18% | +4% | 54 tokens |
| coqa-2 | 15 | +29% | +6% | 164 tokens |

> text 基线每轮把全部历史塞进 prompt → 成本线性堆积；synapse 历史只存一次、按需取相关 → 成本近平稳。**对话越长，省得越多**。

## 二、机制验证：记忆增长 → 残差率下降（赛题 状态传递 20 分）

### 2.1 合成关联序列（signal, 5 轮，真实 API）

| 序列类型 | 残差率轨迹 | 前半→后半 | drop% | 命中率 |
|---|---|---|---|---|
| **linked（关联）** | 82, 58, 56, 38, 32 | 70 → 42 | **40.0%** | **0.8** |
| negative（对照） | 34, 66, 46, 66, 62 | 50 → 58 | **−16.0%**（不降反升） | 0.2 |

> 关联序列残差率随记忆增长下降 40%，对照序列（互不相关主题）不降反升。因果区分成立。

### 2.2 B3 无记忆 ablation（假设3 归因验证）

| 条件 | drop% | 命中率 |
|---|---|---|
| **B1-full（有记忆）** | **40.0%** | **0.8** |
| **B3-no-mem（记忆清空）** | **6.4%** | **0.0** |

> 记忆清空后 drop 从 40%→6.4%，命中率 0.8→0.0。**残差率下降的主要幅度因果源于记忆复用**。B3 残余 6.4% 为 topic 一致性的非记忆效应（诚实标注）。

## 三、统计边界（诚实标注）

- **能证明**：三数据集 ΔF1 ≥ 0（方向一致）；token 节省 75-84%（硬信号）；记忆归因（B3 ablation）
- **不能证明**：严格非劣（seed=exploratory，单 seed，需 N≥30 × 3 seed 升级 confirmed）
- **遗留**：MuSiQue twohop N=30 因 API 超时未完成（N=10 结果支撑结论）；大规模 seed 补强待后续

## 四、复现命令

```bash
# 离线自检（零密钥）
uv run synapse smoke

# 真实 API 实验
uv run synapse probe                                # 鉴权 + 输出形态
uv run synapse signal --rounds 5                    # P0-1 机制（关联序列残差率下降）
uv run synapse signal --rounds 5 --no-memory        # B3 ablation（无记忆归因）
uv run synapse hotpot --n 20                        # HotpotQA single（ΔF1+0.043）
uv run synapse hotpot --n 30 --retrieval twohop     # HotpotQA twohop（对照，ΔF1−0.127）
uv run synapse musique --n 10 --retrieval twohop    # MuSiQue twohop（ΔF1+0.070）
uv run synapse musique --n 10                       # MuSiQue single（对照，ΔF1−0.066）
uv run synapse coqa --convs 3                       # CoQA 记忆复用（命中 0.92）
uv run synapse m7 --g1 5 --g2 5                     # 跨组记忆复用（G2 复用 G1）

# 可复现性：seed 控制
uv run synapse hotpot --n 30 --seed 1               # P0-4 题序 shuffle（同 seed 可复现）
```
