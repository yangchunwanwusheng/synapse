# 决赛前源码彻查报告（2026-08-27）

> 审查方式：三路 strong-model-adviser 并行独立审查（A 核心机制域 / B 协议运行时与计数域 / C 统计与实验域），只读，含动态验证（篡改注入实测）。全程 21 个测试通过，但测试未覆盖下述关键语义。
> 用途：①决赛方案的规划输入；②团队修复工作的依据；③数字改口的存档证据。本报告所有条目为**已验证事实**（源码+存档+动态验证交叉确认），置信度：高。

## 一、总体结论

**当前代码是"机制正确的进程内原型 + 口径乐观的评测代管"，不是"已实现端到端系统"。** 核心算法（残差编解码数学、检索、演化链过滤）本身无误，但：旗舰数字的**归因、口径、统计解释、证据链拼接**四方面全部存在问题；残差/VLC 机制**不在真实任务数据通路中**；对外叙事与代码现实之间存在系统性落差。决赛前必须先修地基（真通路、真口径、真统计），再谈数据平面。

## 三、P0 清单（合并三路去重，决赛生死项）

- **R-P0-1 残差/VLC 不在真实数据通路**（A）`modes/synapse_mode.py:95-177`：接收方校验前已从 CAS 取得全文（L132-134）；重构向量仅作布尔校验；总结器消费 `recv_text`（L175-178）。删掉重构逻辑答案不变。
- **R-P0-2 checksum 从未校验**（A）`residual.py:54-57,94-100`、`checksum.py:23-24`：生成 pkt.checksum 但运行路径无 verify 调用；动态实测篡改后余弦 True / 哈希 False。
- **R-P0-3 no-residual 消融只是改账**（A）`synapse_mode.py:112-117`：开关仅改指标数字（dim×2+12、nnz=dim），数据路径未变。动摇 EC5 对 LatentMAS 的定量差异化。
- **R-P0-4 三档协议只有标签 + CNR 未驱动传输**（A+B）`synapse_mode.py:98-129`、`handshake.py:48-57`：residual/embedding 同一 codec.encode；冷启动也标 residual；`negotiate()` 从未被调用；真实模型仍标 mock-family。
- **R-P0-5 71% 归因错误**（A+B）`qa/pipeline.py:212-293`：QA 路径不用 ResidualCodec、不用四 CodeAgent（四角色提示确实分化存在，但 71% 路径是同一 answerer 的全文 vs top-k 对比）。
- **R-P0-6 ToM encoder-oracle 选基**（A）`tom.py:26-46`：无当前轮泄漏（候选在写记忆前冻结），但以 cos(candidate,Y) 选基=目标感知 codebook 选择；接收方直接复用发送方 b_hat 对象而非按 base_handle 解析。
- **R-P0-7 字节口径双层问题**（B）`eval/metrics.py:37-69`、`messages.py:57-75`：wire_bytes 手工相加且 header_bytes 排除 capability/meta/text 字段；synapse 单边省略共享状态建立成本（CAS 写入、embedding 请求不计）。
- **R-P0-8 评分口径不完整**（C）`scoring.py:12-31`：MuSiQue answer_aliases 抓取时丢弃；EM 未实现；CoQA 单参考；中文无空格退化单 token。
- **R-P0-9 伪重复 CI**（C）`qa/harness.py:88-123`：N×R 差值池化按 IID bootstrap（50 题×3=n_pairs 150），CI 过窄。
- **R-P0-10 统计解释错误**（C）`sweep_hotpot_k.py:65-77`、`cli.py:447-456`：非劣界 −0.03 未通过（两数据集 noninferior=false）却被 README 写成"质量统计不可区分/中性"；CI 含 0 ≠ 等价。
- **R-P0-11 证据链跨模型拼接且不可复算**（C）：71.09%（新模型 N=10）+ CI（旧模型 N=200）；k-sweep 存档无 qid/预测/金标/逐题 F1；77 个 run 无 code_sha/dataset_version/预测文本。
- **R-P0-12 合成 AB 聚合缺真实 token**（B）`eval/harness.py:42-65`：llm token 字段未累加（实跑 0.0），旧代理指标 36.43% 并存混淆。
