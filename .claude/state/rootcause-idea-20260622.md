## A. 根因分析（基于在手数据）

### 根因 1 ·「收缩律」的真身 = 条件率失真 + 结构地板（不是平滑单调律）
- **现象**：full ablation 曲线（真实, rounds10）`[3594,1347,1749,1749,1380,2151,2250,1548,2169,1989]`
  = 冷启 3594 → 任务2 陡降 1347 → 之后 ~1350-2250 **噪声平台**。非"平滑下降"。
- **机制**：残差字节 ≈ 在接收方可预测边信息 B̂ 条件下编码 Y 所需的率 = Wyner-Ziv 条件率失真 R_{Y|B}(D)。
  - 任务1 冷启：无共享记忆 → B̂≈0 → 残差=Y 全量（3594B，≈ H(Y)）。
  - 任务2+：首个相关记忆出现 → B̂ 变可预测 → 残差**坍缩**（1347B）。
  - 平台：每个新 G1 任务有**不可约新意** → 残差落在 H(Y_t|B) 地板，噪声=逐任务新意波动。
- **结论**：正确表述 = "记忆出现即坍缩 + 在结构地板上的噪声平台"，本质 = **可预测性驱动的条件编码**。
  弃用"平滑单调收缩律"（过度承诺，被数据证伪）。

### 根因 2 · online 1.78× 地板的三源分解（决定下一步该补什么）
floor 实验：online `[3528,1746,1920,915,1824,1449,1794,2166,2292,1902]` vs oracle floor_mean 1080，**1.78×**。
分解为三个来源：
1. **时序因果（不可约）**：online 任务 t 只见记忆 1..t-1；oracle 见全体留一 B_∞。早期任务尤其吃亏。
   这是在线运行的内禀代价，**无法靠工程关闭**（除非用未来信息）。
2. **检索宽度（可关闭）**：online k=5 vs oracle k=20 → 加宽检索可缩。
3. **预测基质量（可关闭）**：v1 online 取单条最优基；oracle 也取单条但从全记忆。
   → **巩固器质心原型让 online 取到比任一单条更接近 Y 的基** = mechanism v2 正在测的核心。
- **可证伪预测**：若 v2 质心原型把 1.78× 显著拉近 1（且 no-consolidation 消融重新拉开），
  则地板差的(b)分量被关闭，地板故事变干净；若不变 → 需根因 3 的学习式预测基。
- ✅ **v2 已证实（`runs/mech_*_20260622_165459/`）**：
  - floor：online 2011→1027（drop **48.9%**），second/floor **0.889**（< 1，online 后半**低于**单条最优地板）
    → 质心=充分统计，给出比任一单条更好的预测基，揭示更低的**分布地板**。(b)分量关闭甚至超额。
  - **ablation 阶梯（4 级，干净）**：no-residual(全潜/LatentMAS) 4108 → no-tom(零基稀疏) 3589
    → no-consolidation(单条预测) 2039 → full(质心预测) **1522**。每加一层利用结构的机制，残差率单调降。
  - **consolidation 因果必要性**：full 后半**收缩 +22.9%**；no-consolidation 后半**反升 −17.3%**(mean 2039 vs 1522, +34%)
    → 巩固是**持续收缩**的因（v1 巩固器 no-op 时此消融≈full，现显效）。根因 3 学习式预测基**暂不需要**（质心已够）。
  - drift：回弹 **+191.6%**（强于 v1 的 +85%）+ 回弹后再收缩 35.9% → 漂移传感稳健。

### 根因 3 · 对 LatentMAS 的差异化已量化且就是"残差"
- no-residual（≈LatentMAS 全潜传输）4108B vs full（残差）1993B → **残差编码再省 ~51%**。
- 信息论语义：no-residual 发**无条件**率 H(Y)；full 发**条件**残差 H(Y|B)。
  这 ~106% 的差 = H(Y)−H(Y|B) 的经验值 = 与 LatentMAS 的本质区别（黑盒 API 下潜传输不适用，残差适用）。

## B. idea 增补（按风险/价值排序）

### 头牌重构 A ·「协作即条件率失真编码」（低风险高价值，证据已在手）
统一三块证据为一条原理脊柱，**取代**既冒险又部分的"收缩律发现"、也避开拥挤的"又一省 token"：
> 多智能体协作中，agent 需传输的信息 = 待传内容 Y 对接收方可预测边信息 B̂_j（由共享记忆复现）
> 的 Wyner-Ziv 残差；随协作累积共享结构，该残差趋向条件率失真地板 R_{Y|B}(D)。
> 这**解释**了：① 结构句柄+检索为何省 70-83% token 不掉质量（CC1, 2 数据集）；
> ② 残差编码为何比全潜传输再省 ~2×（vs LatentMAS, no-residual 消融）；
> ③ 残差率本身为何是**免费、免标注的新意/漂移传感器**（见 B-novel）。
- 措辞诚实：把"律"降为"残差趋条件率失真地板"（数据支持：地板存在+坍缩+no-residual 差），
  弃"平滑单调"。顶会形态 = 原理(率失真) + 强实证(CC1) + 干净消融(vs LatentMAS) + 涌现能力(漂移传感)。

### 新颖能力 B ·「通信成本即免费分布漂移/新意传感器」（高新颖，已初证）
- 因残差字节 ≈ H(Y_t|共享记忆)，其跳变标示任务携带集体未内化的信息 = 新意/漂移。
- ✅ **drift-detect 已跑（`runs/drift_detect_20260622_170916/`，真实 API，warmup5+24测）**：
  familiar **1240.6B** vs drift **3843.0B**（3.1×，**零重叠**：fam≤1794, 所有 drift≥3666）；
  **AUC(残差字节)=1.0**，最优阈值检测 P1.0/R1.0@3666B。→ 通信成本是完美、免标注的新意传感器。
- ⚠ **诚实 caveat（→ 下一实验）**：本**二分**设定(熟悉 vs 全无关)里**检索相似度基线也 AUC=1.0**（fam sim~0.54 vs drift 0.12-0.23）。
  二者打平 → 残差的**独有价值未显**。残差 > 检索相似度之处在**分级新意**：
  **同主题但新侧面**(evolved)→检索仍命中(sim 高=判"熟悉")但残差升(新信息不可预测=判"新意")。
- **下一实验（graded-drift，待建）**：三类 familiar / evolved(同topic新aspect,如 g2_family) / novel，
  证残差给**分级**信号(低/中/高)而检索相似度**混淆** familiar+evolved（同主题 sim 都高）。这才是残差的独有价值。
- 退一步（即便分级也打平）：残差是**你已在付的通信成本**(零额外开销) + **以字节标定**(可解释漂移幅度)，
  优于需独立计算/无量纲的 cosine 阈值。价值：拥挤省 token MAS 里**无人**把压缩残差当监控仪 → 干净二级贡献。

### 机制强化 C ·「学习式预测基闭合地板差」（条件触发：v2 不够才上）
- 若 v2 质心原型只部分闭合地板差，下一杠杆 = 学习式预测基（检索加权组合 / 轻在线先验），
  自监督信号 = "残差是否在阈值内重构成功"（避开"信念无 ground truth"）。
- 升级论点为"协作即**学习式**压缩——agent 习得共享码本"，更 ML-conference 形态。
- **门控**：仅当 v2 地板差未闭合才投入，避免过度工程。
